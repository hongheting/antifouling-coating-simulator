# 示例数据说明 / Example lab & shortlist data

**中文：** 本仓库 `data/lab-proxy-table.csv` 与 `data/recommendation-shortlist.csv`（及对应 `recommendation-*-V0.md`）为 **示例数据**，用于演示模拟器表格、标签与短名单结构。  
它们 **不是** 作者课题的实验室配方、微宇宙观察或未发表实验结果。真实手机/桌面应用可使用私有数据源；公开仓库刻意替换为虚构牌号与公开品类示意。

交互配方沙盒、航线—船速耦合和 ISO 10890 / PVC 计算器给出的是**模型包络**。包络、厂家标称和文献界都不是实测。

**English:** Track A lab rows and Track C shortlists in this public repo are **example / placeholder** data. They do **not** contain the author’s unpublished thesis formulations or experimental results. Tags such as `厂家标称`, `待测`, `相对等级`, and `方案非实测` still apply; do not treat example numbers as measurements.

The formulation sandbox, route–speed coupler, and ISO 10890 / PVC calculators add **model envelopes** on top of these rows. An envelope, an OEM nominal, or a literature bound is still not a measurement.
