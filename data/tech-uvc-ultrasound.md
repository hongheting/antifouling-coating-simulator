## 1. UV-C（约 200–280 nm）防污

### 1.1 原理（高层）

- UV-C 可损伤微生物 DNA/RNA 与部分幼体，抑制定殖或杀死早期生物膜。  
- 船体应用面临：**水衰减、阴影、距离、LED 输出稳定性、聚合物/涂层光老化、功耗与密封**。  
- 更现实的落点：niche 区（海箱、推进器隧道、传感器窗）、移动式/ROV 照射、嵌入式 LED 瓷砖试点——而非已验证的「整船外壳唯一方案」。

### 1.3 商用/产品语境（非涂料 TDS）

- 船体 UV-C 整船方案仍多处**原型/试点**阶段；不可与 Hempel/Jotun SPC 的 docking-interval 宣称直接对标。  
- 安全：UV-C **不可**直视；需护目与皮肤防护；对船员、码头作业与海洋生物暴露做单独评估。模拟器安全旗：`UV-C`。

### 1.4 对模拟器的含义

- 轨 C 可增加候选类型 `tech-uvc`（辅助/混合），证据 tag=`文献界`/`公开资料`。  
- **不要**把 UV-C「污损减少 %」填进用户 示例双组分环氧 行。  
- 与涂料混合时：标明「涂层 + 局部 UV」为系统方案，分别溯源。

## 2. 超声（超声波 / 导波）防污

### 2.1 原理（高层）

- 换能器在壳板激励振动/导波，干扰幼体附着或破坏早期生物膜；**预防优于清除**。  
- 效果强烈依赖：**频率、功率、换能器间距与布局、壳板几何与阻尼、电源占空比**。  
- 现场结果不一致：部分试验板洁净，部分商用系统对藤壶有抑制但对水线藻类/粘液/水螅类不足。

## 3. 混合主动体系（高层）

| 组合 | 逻辑（框架） | 注意 |
|------|--------------|------|
| SPC/铜漆 + 超声 | 涂层提供基线杀生/抛光；超声降低闲置期定殖峰值 | 双重成本；涂层完整性与换能器安装干扰 |
| FRC（硅酮/氟聚）+ 航速管理 | 低表面能靠剪切脱附；需足够航速/清洗策略 | 长港停（新加坡、巴拿马闸区）拟合弱 |
| 涂层 + UV-C niche | 海箱/冷却器/传感器窗局部 UV；外壳仍涂层 | UV 老化涂层；电安全 |
| MGPS / 电解铜离子（海箱） |  niche 区电解防污（如 Cathelco MGPS 叙事） | ≠ 外壳防污漆；铜排放合规 |

**GCB 对齐**：热带–亚热带高再定殖压力优先「抗沉降 + 持续表面更新」；温带→冷水提高耐久/抗持久附着权重；混合主动体系按**航段序列**配置，勿单港优化（见 `climate-route-profile.md` / GCB §4.2）。

## 4. 安全与合规清单（常驻）

1. **UV-C**：护目、遮挡、联锁；勿照射皮肤；评估聚合物降解与臭氧（若产生）。  
2. **超声**：听力/振动职业卫生；海洋哺乳动物与鱼礁区政策；壳板疲劳个案评估。  
3. **杀生剂涂层**：IMO AFS、欧盟 BPR、地方铜限制（淡水/波罗的海等）。  
4. **实验室**：溶剂、异氰酸酯（B 料）、UV-C 实验 —— 少做实验 ≠ 零风险。
