防污涂料配方模拟器

面向海洋防污涂层研究的三轨证据面板：轨 A 实验室剂量—代理性能、轨 B 全球航线相对污损压力、轨 C 证据短名单，并汇集文献界、商用技术与行业动态。

⚠ 模拟 ≠ 实测 · 所有数值均带证据标签，非实验室报告值或航次污损率

⚡ 交互式配方沙盒与防污工程计算器（全球同行通用工具箱）

不仅是静态文献与数据看板——拖动滑块即可实时推演微胶囊/杀生剂掺量、分散剂与干膜厚度包络，耦合航速与港停时间重排涂层短名单，或使用 ISO 10890 质量平衡法与 PVC/CPVC 配方计算器。

    怎么用（一页流程）

    1. 打开轨 A：按路线芯片看示例配方槽（公开仓库为示例数据，见 docs/example-data.md）；性能空格为待测，不得把空格或模型包络写成实测。
    2. 打开轨 B：点选全球走廊或冷端桩，看相对污损压力（1–5）与策略提示。
    3. 打开轨 C：按航线筛选短名单 — 排序是工况拟合，不是魔法最优分。
    4. 打开文献界：按技术分类筛选（金属熔覆/喷涂、硅改性、FRC、SPC 铜、水凝胶、UV-C、超声、天然杀生剂等；DOI 可溯源）。
    5. 打开商用·技术：主流市售产品线 + UV-C/超声辅助技术 + 全球目录候选。
    6. 打开行业动态：按周查看法规/企业/产品/技术动态（来自「防污行业周报」，公开资料，非性能数据）。
    7. 任何数值旁看标签颜色：实测 / 待测 / 厂家标称 / 粗估观察 / 文献界 / 相对等级 …

    🧪 模块 1 · 配方剂量—代理性能包络沙盒 (Formulation Dose–Response Sandbox)

    模型包络推演 · 非实测真值
    基料树脂网络 (Resin Matrix)
    功能填料 / CA@MSiO₂ 掺量 (wt% 总固) 2.0 wt%
    0% = 空白原漆；1–3% 常用筛选窗；>5% 需警惕颗粒团聚与表面粗糙度抬升
    润湿分散剂 BYK 用量 (wt% 相对粉体) 3.0 %
    适度助剂解团聚；过量 (>6%) 可能增塑交联网络或导致界面滑移降附着
    目标干膜厚度 DFT (μm) 40 μm
    粒径 ~5 μm 时，过薄 (<25 μm) 易刺破膜面粗糙；过厚致密环氧内部药剂难以扩散
    基材与表面处理 (Substrate)

    🚢 模块 2 · 航线—船速—港停动态污损耦合模拟器 (Dynamic Route–Speed–Idle Coupler)

    GCB 增长–脱附动态耦合 · 相对等级
    选择全球航线剖面 (Route Corridor)
    平均营运航速 (Steaming Speed) 14.0 kn
    硅酮 FRC 通常需 >10–12 kn 水动力剪切实现藤壶自清洁；低速船更依赖主动/缓释抗定殖
    港口停泊 / 锚地静置比例 (Port Idle Ratio) 20 %
    港停期间无水流剪切且近岸幼体密度高，高港停率会显著放大热带走廊定殖压力
    目标坞期 / 维护周期 (Docking Cycle) 36 mos
    辅助主动防污配置 (Auxiliary Active Tech)

    工况耦合后：各技术路线相对拟合度动态排序（非实测打分）

    📐 模块 3 · 国际防污涂料工程师通用计算器 (ISO 10890 Leaching & PVC/CPVC Calculators)

    标准质量平衡 / 配方体积模型

    ⏱️ A. 杀生剂浸出率与有效防污期计算器 (ISO 10890 / CEPE Mass-Balance)

    根据涂层干膜内活性防污剂总储量与目标临界释放通量，推算理论有效防污寿命与所需的最低干膜厚度（DFT）。

    🧪 B. 颜料体积浓度 (PVC / CPVC)、体积固含与理论涂布率计算器

    输入基料树脂、颜填料/微胶囊与溶剂配比，实时计算 PVC、CPVC、约化颜料体积浓度 Λ = PVC/CPVC 及成膜致密/抛光状态诊断。
