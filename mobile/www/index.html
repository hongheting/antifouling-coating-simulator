防污涂料配方模拟器

面向海洋防污涂层研究的三轨证据面板：轨 A 实验室剂量—代理性能、轨 B 全球航线相对污损压力、轨 C 证据短名单，并汇集文献界、商用技术与行业动态。

⚠ 模拟 ≠ 实测 · 所有数值均带证据标签，非实验室报告值或航次污损率

    怎么用（一页流程）

    1. 打开轨 A：按路线芯片浏览示例配方行；性能空格为待测。公开仓库轨 A 为示例数据（见 docs/example-data.md）。
    2. 打开轨 B：点选全球走廊或冷端桩，看相对污损压力（1–5）与策略提示。
    3. 打开轨 C：按航线筛选短名单 — 排序是工况拟合，不是魔法最优分。
    4. 打开文献界：按技术分类筛选（金属熔覆/喷涂、硅改性、FRC、SPC 铜、水凝胶、UV-C、超声、天然杀生剂等；DOI 可溯源）。
    5. 打开商用·技术：主流市售产品线 + UV-C/超声辅助技术 + 全球目录候选。
    6. 打开行业动态：按周查看法规/企业/产品/技术动态（来自「防污行业周报」，公开资料，非性能数据）。
    7. 任何数值旁看标签颜色：实测 / 待测 / 厂家标称 / 粗估观察 / 文献界 / 相对等级 …
