# 防污涂料配方模拟器 · 工具版（微信小程序）

原生小程序（WXML / WXSS / JS），**个人主体**可发布的「工具」版：
- 全部数据内置在包里（`data/data.js`，由 `ui/data-snapshot.json` 生成），**不联网**、不登录、无广告、无用户发布内容（UGC）。
- 与网页版同口径：筛选、排序、统计逻辑在 `utils/core.js`，测试保证与 `ui/index.html` 输出一致。
- 诚实规则不变：**模拟 ≠ 实测**；每个数值带标签（实测 / 待测 / 厂家标称 / 粗估观察 / 方案非实测 / 文献 / 相对等级 / 框架推断…）；未测显示「待测」。
- 外部链接无法在个人小程序中打开，一律「复制链接」。技术交流只做说明页（复制 GitHub 链接），不能发帖评论。

## 页面
| 页面 | 内容 |
|---|---|
| 总览（tab） | 数据概览、各板块入口、诚实/安全提示 |
| 航线选型（tab） | 轨 B：离线示意航迹地图 + 12 条航线、气候带、相对压力、各航段 → 跳轨 C |
| 文献（tab） | 文献界：分类、工艺、搜索、主观星级、复制 DOI/链接 |
| 关于（tab） | 诚实边界、数据版本、隐私说明、隐私指引入口 |
| 轨 A · 实验室表 | 基料分组、标签筛选、搜索，卡片式显示拉拔/EIS/HPLC/微宇宙 + 标签 |
| 轨 C · 短名单 | 按航线的证据短名单（排序=工况相对拟合） |
| 商用 · 技术 | 目录候选 / 商用产品线 / UV-C·超声摘录 |
| 行业动态 | 按周 / 全部周次，类别、相关度、搜索 |
| 防污学者排行 | OpenAlex 领域 h 指数，搜索、只看文献界作者 |
| 技术交流 | 说明 + 可选「复制讨论区链接」（无发帖、无 APK 引导） |

每页底部：「由洪鹤庭 Jassyhong 开发」（不展示电话）。开发者电话仅在「关于」页可选拨打。

主包约 0.4 MB（< 2 MB），无需分包。

## 更新数据
```bash
cd miniprogram
npm run data   # 从 ../ui/data-snapshot.json 重新生成 data/data.js
npm test       # 需要 jsdom、htmlparser2：npm i
```
然后在开发者工具里上传新版本。以后若要不发版就更新公开板块，见 `utils/datasource.js` 里的「微信云开发」预留说明（只更新公开板块，不碰实验室表/短名单；不要请求 GitHub / jsDelivr / workers.dev）。

## 发布步骤（个人主体）
1. **注册**：打开 https://mp.weixin.qq.com → 立即注册 → 小程序 → 用一个**未绑定过公众号/小程序的邮箱**注册 → 邮箱激活 → 主体类型选「**个人**」→ 身份证 + 管理员微信扫码实名。
2. **补充信息**：小程序名称（可先用「防污涂料配方模拟器」，重名会提示）、头像、简介（见下）、**服务类目：工具 > 信息查询**（个人可选、无需资质）。
3. **AppID**：后台「开发管理 → 开发设置」复制 AppID，替换 `project.config.json` 里的 `"appid": "touristappid"`。
4. **用户隐私保护指引**（必须）：后台「设置 → 服务内容声明 → 用户隐私保护指引」，勾选声明 **「剪切板」**（用于复制链接），说明：仅在用户点击「复制链接」时把公开网址写入剪切板，不读取剪切板。不收集其它个人信息。
   - 现行规则（2023-10-17 起默认启用）：无需在 app.json 配 `__usePrivacyCheck__`；首次调用剪切板时微信自动弹出**官方隐私授权弹窗**。用户拒绝时本程序会弹窗显示链接文本，可长按复制。
   - `wx.makePhoneCall` 不在隐私接口清单内，无需声明。
5. **ICP 备案**（2023-09 起小程序上架前必须）：后台「设置 → 基本设置 → 小程序备案」→ 选个人 → 填身份证、手机、居住地 → 服务内容标识选 **工具** → 上传身份证正反面 + 人脸核验 → 平台初审（约 1–2 个工作日）→ 工信部短信核验（24 小时内完成）→ 省管局审核（约 1–20 个工作日）。备案号会在小程序资料页显示。
   - 名称/简介里避免「平台、社区、论坛、资讯」等字样，个人主体做资讯/社区会被拒。
6. **开发者工具**：安装「微信开发者工具」→ 导入项目 → 目录选本文件夹 → 填 AppID → 编译预览 → 真机预览检查 → 「上传」（版本号如 1.0.0）。
7. **提交审核**：后台「版本管理 → 开发版本 → 提交审核」，审核说明可写：
   > 本小程序为防污涂料选型的**本地信息查询工具**，数据随包内置、不联网、无需登录、无用户发布内容。页面中所有数值均标注证据来源（实测/厂家标称/文献/模型估计等），并明确提示“模拟 ≠ 实测，仅供参考”。外部链接仅提供复制，不内嵌网页。
8. 审核通过后点「发布」。


## 合规注意（个人主体）
- 本工具版**不引导下载其他 App**，技术交流页只提供可选的「复制讨论区链接」，无 APK 下载按钮。
- 页脚不展示电话号码；号码仅出现在「关于」页，标签为「开发者电话（可选联系）」。
- 不联网、不登录、无 UGC/广告/web-view；航线图为示意性离线 canvas，非 AIS。

### 审核风险提示（如实标注）
- 「行业动态」是对公开资料的整理。若审核认为属于“资讯”（个人主体不开放），可在 `pages/index/index.js` 去掉该入口并从 `app.json` 删除 `pages/industry/industry` 后重新提交。
- 不要在小程序内加入发帖/评论/网页跳转，个人主体不允许 UGC。
- 涉及杀生剂（铜系等）只做选型信息与安全提示，不做销售或功效承诺，标签已注明“厂家标称/文献”等性质。

### 小程序简介草稿（≤120 字）
> 防污涂料选型信息查询工具：按航线气候带查看相对污损压力与证据短名单，浏览实验室配方表、文献、商用产品与学者信息。所有数值标注来源（实测/厂家标称/文献/估计），模拟不等于实测，仅供参考。
